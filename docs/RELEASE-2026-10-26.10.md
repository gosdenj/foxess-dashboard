# Release 2026-10-26.10 — the chart that had gone quiet

The **Grid — last 24 hours** chart on the Usage slide stopped drawing.
The bars were there, but they were a thousand times too small to see.

## What was wrong

The half-hourly history integrates the live power into energy. The live
feed is in **kW** — `foxess/ws.py` converts it on the way in — and the
history was dividing by a thousand as well:

```python
# the live power is in watts and dt is in hours, so this is
# watt-hours - the figures are in kWh
bucket[key] = bucket.get(key, 0.0) + value * dt / 1000.0
```

The comment says the power is in watts. It has not been for a long time.
So every figure the chart drew was a thousandth of what it should have
been, and the chart's scale — which has a floor of 0.25 kWh — put them
all on the baseline.

The proof is in the inverter's own hourly report, which is in real kWh:

```
the hour         the inverter says   the history recorded
21:00            1.0 kWh             0.00049 kWh
```

## Why it had been working

The chart was not always drawing the local history. `usage_payload()`
fell back to the inverter's hourly report whenever the local history was
nearly empty:

```python
if len(series) < 8 and hourly:
    series = hourly
    granularity = "hour"
```

The inverter's report is in real kWh, so the chart looked right — until
the local history grew past eight half-hour slots, which is four hours
of the dashboard running. At that moment the chart stopped using the
inverter's figures and started using the broken local ones, and went
quiet.

So the bug was there all along, waiting for four hours of running to
show itself.

## What is done now

- **The scale.** kW times hours is kWh. The extra thousand is gone, and
  `HISTORY_VERSION` is now 3, so the old file — with its thousand-fold
  figures — is discarded rather than mixed in with the real ones.
- **The handover.** The local history is only used once it has filled
  the whole 24 hours the chart shows. Before that the inverter's own
  hourly report draws the chart, so the chart never ends up empty for
  most of the day. The handover used to happen at four hours, which is
  exactly when the local history covers the *least* ground.
- **The demo.** The demo's made-up history was fed in watts, while the
  live feed is in kW — two different scales for the same history. It is
  all kW now.

## The solar fit was affected too

The same history feeds the solar calibration when the inverter's own
report is missing, so its solar figures were a thousandth of the real
ones. That is fixed by the same change, and the history will fill in
again as the dashboard runs.
